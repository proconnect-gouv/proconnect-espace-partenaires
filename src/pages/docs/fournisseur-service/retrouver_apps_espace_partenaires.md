# Connexion à l’Espace Partenaires via ProConnect

La connexion à l’Espace Partenaires se fait uniquement via **ProConnect**. Les liens de connexion envoyés par e-mail ont été supprimés.

## Si l'e-mail de rattachement de votre application n’est pas lié à un compte ProConnect

Si vos applications étaient rattachées uniquement à une adresse e-mail qui n’est pas liée à un compte ProConnect (par exemple une adresse e-mail d’équipe), elles ne sont plus accessibles. Il faut alors **recréer une application d’intégration** en vous connectant avec votre compte ProConnect, puis y ajouter les adresses e-mail individuelles des membres de l’équipe via la fonctionnalité d'ajout de personnes collaboratrices.

Pour toute question, consultez le [centre d’aide ProConnect](https://proconnect.crisp.help/fr/).
