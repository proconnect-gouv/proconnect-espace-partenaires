# Contributing

Thank you for your interest in contributing! We welcome improvements, bug fixes, and new features. To keep our workflow smooth and consistent, [please refer to the ProConnect team guidelines](https://github.com/proconnect-gouv/federation/blob/main/CONTRIBUTING.md).

If you contribute with the help of an AI coding agent (Claude Code, Codex, Cursor, Copilot, Gemini CLI…), the rules for this repository are in [AGENTS.md](AGENTS.md) — application code and documentation — and in [`e2e/AGENTS.md`](e2e/AGENTS.md) for the end-to-end tests.
